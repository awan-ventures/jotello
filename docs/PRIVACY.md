# Privacy

Jotello is a local screenshot and feedback app.

- **Screen content:** Jotello captures the screen only when you start a capture. The image and annotations stay on your Mac. Jotello does not upload screenshots.
- **Saved captures:** Each time you send feedback, Jotello saves the annotated screenshot and its text in `~/Library/Application Support/Jotello/Captures/`, so agents can open the image by path. Delete that folder (right-click the menu bar icon → Show Captures in Finder) to remove them.
- **Output:** Images and text go only where you send them: the macOS clipboard, a file location you choose, or a web page Jotello opens in your browser for you to review and submit. Other apps can read the clipboard according to macOS behavior.
- **Preferences:** Settings are stored locally. Launch at login is managed by macOS.
- **Data collection:** No analytics, tracking, advertising, accounts, network services or third-party SDKs.
- **Permissions:** Screen capture permission is used for screenshots only. You can revoke it in System Settings.

Screenshots can contain sensitive information. Check what you capture before you share it publicly.
